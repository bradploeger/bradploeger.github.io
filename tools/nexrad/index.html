About

Heights are above the radar, using the standard 4/3 earth beam model. Velocity is shown as recorded, with no dealiasing. Boundaries: US Census cartographic files via us-atlas (1:10M). Cities and interstates: Natural Earth (1:10M). Map lines are simplified. Data: NOAA NEXRAD Level II via the AWS open data archive.
